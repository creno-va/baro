# Pretendard

Unmodified Pretendard Variable v1.3.9 from the official distribution:
https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable

`PretendardVariable.woff2` is served from this origin; no font CDN requests.
The copyright notices and SIL Open Font License 1.1 are retained in `OFL.txt`.
The family is `Pretendard Variable`, weight range 45–920, with `font-display: swap`.

`BaroReport-Regular.ttf` is a static weight-400 derivative for Workers PDF exports.
It keeps the original character repertoire and uses the distinct family **Baro Report**
to respect the Reserved Font Name. Regenerate with `python3 scripts/build-report-font.py`
using fonttools 4.66.1 and brotli 1.2.0. It is fetched from the local ASSETS binding and
embedded in PDF; the original copyright and OFL license above still apply.
