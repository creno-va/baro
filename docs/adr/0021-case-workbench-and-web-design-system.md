# ADR-0021: 사건 작업대와 웹 디자인 시스템 교체

- Status: Accepted
- Date: 2026-11-08
- Authority: 전면 리디자인 총괄 채팅의 사용자 직접 지시와 범위 내 설계 판단
- Tracking: [#764](https://github.com/creno-va/baro/issues/764), [실행 계약](../development/REDESIGN-EXECUTION.md)
- Partial supersession: 기존 DS 유지·고정 우측 패널·랜딩/로그인 제외와 ADR0018의 변호사 연결 UI. Workers·원문/분석·권한·버전·비용 계약은 보존한다.

## 맥락

기존 DS를 유지하며 대화·자료 패널·별도 리포트를 이전하는 과정에서 스타일 cascade와
화면 이동 의미가 분산됐다. 긴 한국어 법률 자료를 읽고 비교하고 작성하는 작업에 맞춰
정보 구조와 공통 시스템을 함께 바꿔야 한다. 기획 PR765의 ADR0019 Accepted 범위와
ADR0020 Proposed의 새 저장/admission 제안은 구분한다.

## 결정

1. 대화·자료·리포트·문서 초안 네 작업을 같은 사건 작업대에서 상시 찾게 한다.
   자료는 독립 과업이며, 문장/문서의 근거는 필요한 때 보조 영역으로 펼친다.
2. 기존 React owner와 ReportReview embedded API를 재사용해 작업 전환 시 작성 내용을
   메모리에 보존한다. 새 상태 라이브러리·router·영구 보관을 임의 추가하지 않는다.
   기존 직접 URL·새로고침과 세션/owner fence는 보존한다. 초안은 기존 리포트 내 실제 영역이다.
3. 공통 토큰·UI·shell의 canonical 진입점을 만들고 기존 중복 cascade를 소비 전환 후 제거한다.
   01이 단독 수정하며 다른 화면은 공통 API를 소비한다. native token·PDF 출력 소비를 확인한다.
4. 네 경로는 기존 purpose와 procedure에 연결한다. 설명·문서에서 확인한 정보와 사용자
   확인·미확인을 구분한다. 문서만 admission과 질문 자료 반영은 기존 계약을 확인하고,
   새 계약이 필요하면 별도 사용자 결정을 받는다.
5. 변호사 컨택 UI를 제외하고 기존 변호사 계정의 일반 사건 이용·동의/삭제권을 보존한다.
   공통 로그인은 기존 역할을 덮어쓰지 않는다. 세 리포트 액션은 유지하며 변호사 클릭은
   지정 미지원 모달만 열고 조회·전송·선택 저장·외부 이동·유료 호출 없이 초점을 복귀한다.
6. 실제 자동 저장/출력·공개자산 종료/법률 인수의 지원 범위를 사실대로 표시한다.
   새 API/DB·원격 자산 삭제·배포 완료를 디자인 변경으로 선언하지 않는다.

## 대안

대화 중심+상시 보조 패널은 기존 골격을 재사용하기 쉽지만 자료 비교를 부가 기능에 가둔다.
사건 작업대는 네 과업의 위치를 예측할 수 있고 자료 밀도를 확보하므로 채택한다.
영구 저장소를 새로 도입하는 안은 개인정보·암호화·동시편집 계약이 필요해 여기서 확정하지 않는다.

## 결과와 후속

독립 작업을 복제하지 않고 일관된 공통 API로 합성한다. exact head 기반 PR 의존성과
전체 경로 마이그레이션·인수표는 실행 계약에 기록한다. 합성 브라우저 과업·필수 검사와
실제 공급자/법률/remote 저장/배포 인수는 별도로 보고한다. Accepted는 제품 완료 증거가 아니다.
