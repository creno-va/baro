## 1. Product Summary

### 한 줄 정의

> **법률 문제가 생겼을 때 무엇을 확인하고, 무엇을 준비하고, 어디로 가야 하는지 안내하는 AI Legal Navigator**

BARO는 사용자의 법률 문제를 대신 판단하거나 해결하는 서비스가 아니다.

사용자가 자신의 상황을 정리하고,

- 어떤 법률 쟁점이 있는지
- 어떤 정보를 추가로 확인해야 하는지
- 어떤 증거와 문서를 준비해야 하는지
- 어떤 기관 또는 전문가에게 가야 하는지

이해할 수 있도록 돕는다.

---

## 2. Problem

일반 사용자는 법률 문제가 발생해도 다음 행동을 결정하기 어렵다.

대표적인 문제는 다음과 같다.

- 현재 상황이 법적으로 어떤 문제인지 모름
- 무엇을 검색해야 할지 모름
- 관련 법령이나 판례를 찾기 어려움
- 어떤 증거가 필요한지 모름
- 어떤 서류를 준비해야 하는지 모름
- 경찰서, 법원, 변호사 중 어디로 가야 하는지 모름
- 변호사를 만나더라도 사건을 제대로 설명하기 어려움

BARO는 이 중 **법률 문제의 초기 탐색 및 정리 과정**을 해결한다.

---

## 3. Product Goal

### Primary Goal

사용자가 자신의 사건을 입력한 뒤 **5분 이내에 다음 행동을 이해할 수 있도록 한다.**

### 사용자에게 제공해야 하는 결과

사용자는 BARO 이용 후 최소한 다음을 확인할 수 있어야 한다.

1. 내 상황이 무엇인지
2. 어떤 법률 쟁점을 확인해야 하는지
3. 어떤 정보가 부족한지
4. 어떤 증거를 준비해야 하는지
5. 어떤 절차가 일반적으로 진행되는지
6. 어떤 문서를 준비할 수 있는지
7. 필요하면 어디에서 변호사를 찾을 수 있는지

---

## 4. Non-Goals

BARO는 다음 기능을 제공하지 않는다.

- 승소 가능성 예측
- 사건 유·불리 점수
- 범죄 성립 여부 확정
- 손해배상 가능 여부 확정
- 사용자를 대신한 법적 의사결정
- 특정 변호사의 직접 추천
- 수임 성사 기반 변호사 중개
- 세무대리
- 변호사를 대체하는 전문 법률자문

# 6. Product Principles

BARO의 모든 기능은 다음 기준을 따른다.

### 1. 판단보다 정리

BARO가 답을 내려주기보다 사용자가 판단에 필요한 정보를 이해하도록 돕는다.

### 2. 결과보다 다음 행동

“이길 수 있습니다”보다

> “다음 단계에서 이것을 확인하세요.”

를 제공한다.

### 3. 정보 출처 명확화

법률정보에는 가능한 경우 다음을 함께 제공한다.

- 관련 법령
- 판례
- 공식기관 정보

### 4. 전문가 연결은 사용자 선택

BARO가 특정 변호사를 결정하지 않는다.

### 5. AI 한계 명시

모든 주요 AI 결과는 법률전문가의 검토를 거치지 않은 참고정보임을 사용자에게 알린다.

# 8. MVP Feature Scope

## F01. 사건 입력

사용자가 자연어로 자신의 상황을 입력한다.

### Input

- 자유 텍스트
- 사건 발생 시점
- 상대방
- 현재까지 진행한 조치

### Example

> 두 달 전에 친구에게 300만 원을 빌려줬는데 계속 갚지 않고 있습니다. 카카오톡으로 돈을 빌려달라고 한 대화와 계좌이체 내역은 있습니다.

---

## F02. 추가 질문

입력된 사건을 분석하여 필요한 정보가 부족할 경우 추가 질문을 제공한다.

### Example

```text
돈을 돌려받기로 약속한 날짜가 있었나요?

○ 있음
○ 없음
○ 잘 모르겠음
```

### Rule

질문은 가능한 한 사용자가 이해하기 쉬운 표현을 사용한다.

법률용어 사용은 최소화한다.

---

# 9. 사건 구조화

AI가 입력 내용을 구조화한다.

## 출력

### 사건 요약

사용자의 상황을 3~5줄로 요약한다.

### 사건 타임라인

```text
2026.06
300만 원 송금

2026.07
상환 요청

2026.08
상대방 연락 회피
```

### 주요 관계

```text
사용자
↓ 금전 대여
상대방
```

---

# 10. 쟁점 정리

AI가 사건에서 확인해야 할 주요 법률 쟁점을 제시한다.

### Example

```text
확인해야 할 주요 사항

1. 금전 대여 사실을 증명할 수 있는지
2. 상환기한이 정해져 있었는지
3. 상대방이 채무를 인정한 기록이 있는지
4. 현재 상대방과 연락이 가능한지
```

### 금지 출력

```text
당신은 승소할 가능성이 높습니다.
```

```text
상대방은 사기죄입니다.
```

# 11. 관련 법률정보

사용자의 사건과 관련된 정보를 탐색한다.

## 제공 정보

- 관련 법령
- 관련 판례
- 일반적인 법률 개념
- 공식기관 안내

### UI

각 정보마다 출처를 표시한다.

```text
민법 제598조
소비대차의 의의

[법령 원문 보기]
```

# 12. 증거 체크리스트

사건 유형에 따라 사용자가 확보하면 좋은 자료를 안내한다.

### Example

#### 금전 분쟁

- [ ] 계좌이체 내역
- [ ] 카카오톡 / 문자 대화
- [ ] 차용증
- [ ] 상환 약속 기록
- [ ] 상대방 인적사항

사용자가 직접 체크할 수 있도록 한다.

---

# 13. 추가 확인사항

AI가 사건 해결 전에 확인하면 좋은 사항을 질문 형태로 제시한다.

### Example

```text
추가로 확인해보세요

□ 상대방의 현재 주소를 알고 있나요?
□ 상환 날짜가 명확하게 정해져 있었나요?
□ 상대방이 채무를 인정한 기록이 있나요?
```

---

# 14. 절차 Navigator

사용자가 선택한 목표에 따라 일반적인 절차를 제공한다.

### Example

목표:

> 빌려준 돈을 돌려받고 싶어요.

### Output

```text
1. 증거 정리
↓
2. 반환 요청
↓
3. 내용증명 검토
↓
4. 지급명령 또는 민사소송 검토

```

각 단계는 상세 안내로 확장할 수 있다.

# 15. 문서 작성 보조

BARO는 법률문서를 대신 판단하여 작성하지 않는다.

사용자가 표준 서식을 작성할 수 있도록 돕는다.

## MVP 문서

- 내용증명
- 사실확인서
- 진술서
- 고소장 기본 양식

## Flow

```text
문서 선택
↓
필수 정보 입력
↓
작성 가이드
↓
초안 생성
↓
사용자 확인 및 수정
↓
다운로드
```

### AI 역할

가능:

- 문장 다듬기
- 입력값 정리
- 형식 변환

제한:

- 새로운 사실 생성
- 범죄 성립 여부 판단
- 승소전략 자동 생성
- 법적 주장의 임의 추가

### 제공 정보

# 17. 변호사 검색

전문가 도움이 필요할 경우 변호사를 검색할 수 있다.

## Filter

- 지역
- 업무 분야
- 상담 가능 시간
- 경력
- 상담 비용

### Profile

```text
홍길동 변호사

분야
민사 / 부동산

경력
8년

지역
서울 강남

상담료
30분 50,000원
```

### 제한

BARO는 다음 표현을 사용하지 않는다.

- 가장 적합한 변호사
- 승소율 높은 변호사
- BARO 추천 변호사
- 사건 적합도 95%

사용자가 정보를 비교하여 직접 선택한다.

# 18. AI Response Policy

AI 응답은 세 가지 유형으로 분류한다.

## A. Allowed

- 사건 요약
- 법률 용어 설명
- 관련 법령 검색
- 관련 판례 검색
- 일반 절차 설명
- 증거 체크리스트
- 문서 작성 보조

## B. Restricted

출력 시 반드시 표현을 완화한다.

예:

> 제공된 내용에서는 다음 쟁점을 확인할 필요가 있습니다.

> 일반적으로 이러한 상황에서는 다음 절차가 검토될 수 있습니다.

## C. Blocked

다음 출력을 생성하지 않는다.

- 승소율
- 사건 유불리 점수
- 범죄 성립 확정
- 법률행위 직접 지시
- 특정 변호사 추천

# 20. 개인정보 처리

법률상담 과정에서는 민감정보가 포함될 가능성이 높다.

## 기본 원칙

### 최소 수집

서비스 제공에 필요하지 않은 정보는 요구하지 않는다.

특히 입력 단계에서 다음 정보 입력을 지양한다.

- 주민등록번호
- 상세 금융정보
- 계정 비밀번호

### 개인식별정보 Masking

LLM 전달 전에 가능한 경우 다음 데이터를 비식별화한다.

```text
김현호 → 사용자 A

010-XXXX-XXXX → [PHONE]

주민번호 → [RRN]
```

# 27. Launch Definition

BARO MVP의 성공 기준은

> **AI가 법률 문제를 대신 해결하는 것**

이 아니다.

사용자가 BARO 사용 후

> **“내 상황을 이해했고, 이제 무엇을 해야 하는지 알겠다.”**

라고 느끼는 것을 목표로 한다.

BARO는 법률 판단의 종착점이 아니라 **첫 진입점**이 된다.
