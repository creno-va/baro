# BARO Product Requirements Document

- Version: 1.2
- Status: Approved for MVP implementation
- Updated: 2026-10-05
- Market: 대한민국

## 1. 제품 정의

BARO는 개인 간 금전 대여 문제를 겪는 사용자가 자신의 상황을 빠짐없이 정리하고,
확인할 쟁점·준비할 자료·일반적인 다음 행동을 이해하도록 돕는 웹 서비스다. BARO는
변호사나 법률사무소가 아니며 법률 자문, 승소 가능성 판단, 사건 수임 또는 전문가
추천을 제공하지 않는다.

MVP의 대상은 대한민국에 거주하거나 대한민국 법률이 적용되는 만 14세 이상
사용자다. 만 14세 미만은 가입 및 이용할 수 없다.

## 2. 문제

개인 간 금전 대여 분쟁의 당사자는 사실관계, 증거, 기한, 상대방과의 약속을 한 번에
정리하기 어렵다. 검색 결과는 자신의 상황에 어떻게 적용되는지 판단하기 어렵고,
AI 답변은 출처가 불명확하거나 사용자가 말하지 않은 사실을 섞을 위험이 있다.

## 3. 제품 원칙

1. 사실, 사용자 진술, AI의 정리와 추론을 구분한다.
2. 확인된 국가법령정보 출처만 인용한다.
3. 불확실한 내용은 질문하거나 `확인 필요`로 표시한다.
4. 진단·유불리·성공 가능성 대신 구조화와 다음 행동에 집중한다.
5. 개인정보 최소 수집, 삭제 가능성, 운영 로그 비노출을 기본값으로 둔다.
6. 안전·인용 검사를 통과하지 못한 결과는 사용자에게 표시하지 않는다.

## 4. MVP 목표

- 사용자가 5분 안에 사건 입력과 추가 질문을 완료할 수 있다.
- 사건 요약, 타임라인, 확인할 쟁점, 증거 체크리스트, 일반 절차를 한 화면에서 본다.
- 각 법령 근거의 법령명, 조문, 시행일, 공식 원문 링크를 확인할 수 있다.
- 로그인한 사용자가 결과를 다시 보고 사건과 계정을 삭제할 수 있다.
- 입력 부족, 범위 밖 사건, 긴급 상황, 외부 서비스 장애를 안전하게 처리한다.

## 5. MVP 범위

### 포함

- Google·Naver·Kakao OAuth 가입과 로그인
- 만 14세 이상 확인 및 약관·개인정보·AI 이용 고지 동의
- 개인 간 금전 대여 사건의 자유 서술 입력
- 최대 5개의 적응형 추가 질문
- 공식 법령 검색과 검증된 인용
- 구조화 결과, 증거 체크리스트, 일반적인 다음 행동
- 사건 저장·목록·재열람·삭제와 계정 삭제
- 사용자별 하루 10회 신규 분석 제한
- Turnstile을 통한 사건 생성 남용 방지

### 제외

- 변호사 연결, 사건 수임, 성공보수 또는 소개 수수료
- 승소 가능성, 사건 유불리, 손해액·이자·기한의 확정적 계산
- 판례 추천, 소장·내용증명 등 제출 문서의 완성본 자동 작성
- 세무·형사·가사·노동 등 다른 사건 유형
- 대한민국 외 법역, 만 14세 미만, 비로그인 게스트 이용
- 사용자를 대신한 신고, 제출, 연락 또는 결제

## 6. 핵심 사용자 흐름

```text
랜딩 -> 로그인 -> 필수 동의 -> 사건 입력 -> 범위/긴급성 확인
  -> 추가 질문(0~5개) -> 분석 -> 결과 확인 -> 재열람 또는 삭제
```

세부 기능과 상태는 [MVP 명세](./product/MVP-SPEC.md), 화면과 문구는
[UX 명세](./product/UX-SPEC.md)를 구현 기준으로 삼는다.

## 7. 성공 지표

| 지표 | 정의 | MVP 목표 |
| --- | --- | --- |
| 입력 활성화율 | 사건 입력 화면 방문자 중 제출자 | 70% 이상 |
| 분석 완료율 | 제출 analysis 중 완료 결과를 열람한 analysis 비율 | 60% 이상 |
| 행동 전환율 | 결과 열람자 중 증거 확인 또는 출처 열람자 | 30% 이상 |
| 신뢰 응답률 | 결과가 상황 정리에 도움이 됐다고 답한 비율 | 80% 이상 |
| 완료 시간 | 사건 입력 시작부터 결과 표시까지 | p75 5분 이하 |
| 안전 게이트 | 출시 평가셋의 허구 사실·미검증 인용·금지 출력 | 각각 0건 |

이벤트와 분모는 [분석 이벤트 명세](./analytics/EVENTS.md)에서 고정한다.
제품 지표는 선택 analytics에 동의한 production cohort로 계산하고 표본/결측을 함께
표시한다. opt-out 사용자를 자동 실패나0으로 포함하지 않는다.

## 8. 출시 정의

MVP는 공개 베타로 출시한다. P0 인수 조건, 보안·AI 평가, 데이터 삭제, 장애 복구,
정책 문서의 법률 검토가 모두 통과해야 한다. 정책 초안의 게시 차단 항목과 기존
랜딩 페이지의 제품 표현이 해소되지 않으면 공개 출시하지 않는다.
