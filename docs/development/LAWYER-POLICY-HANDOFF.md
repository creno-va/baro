# 변호사·정책 초안 인수와 미확인 사실

- Reviewed: 2026-10-14 KST; [ADR-0015](../adr/0015-maintenance-and-operating-policy.md).
- #20/#70은 정책 초안·사업자 플레이스홀더를 수용한 범위로 완료됐다. 현재 공개 서비스를 유지한다.

고객/변호사 두 역할과 자기 프로필·직접 외부 연락을 제공하고 승인 어드민·자격 심사 UX는
MVP에서 제외한다. 자기 선택 role을 자격 확인으로 표시하지 않으며 기존 심사 backend와
검증된 자격 표시를 보존한다. 비공개 사건·자격 자료를 공개 검색 projection에 넣지 않는다.

실제 사업자등록·대표/주소·책임자/권리행사 연락처, 처리 국가·위탁/국외 이전·계약/보존,
민감정보·미성년·정책 게시 시행일과 법률 검토는 미확인 사실로 유지한다. 초안 인수나 배포
허가를 이 사실의 승인으로 바꾸지 않는다. 사업자/법률/개인정보 책임자가 실제 근거를 제공하면
총괄이 검토 범위·문서 버전·검토일·비민감 reference를 기록한다. 미지정 개인의 자격·승인을 발명하지 않는다.

기존 정식 공개 checker의 법률·정책·외부 검증 미완료 조건은 그대로 검사한다. 이 조건은
현재 공개 유지·초안 인수와 구분하고 #71의 전체 실제 인수에서 독립적으로 표시한다.
정비 종료만으로 전체 MVP 종료를 선언하지 않는다.

### 다음 자료를 받을 때 기록할 항목

사실 제공자 또는 검토 담당 역할, 확인일, 적용 기능·환경·문서 버전, 원문이 보관된 비공개
reference, 승인/조건부/보완 필요의 정확한 결과와 남은 행동을 기록한다. 외부 검토자에게
연락하거나 자료를 전송한 상태가 아니며, 내부 점검표 존재를 법률 승인으로 표시하지 않는다.
현재 사업자 미정과 초안 인수는 유지하며 #20/#70을 이 점검 때문에 다시 열지 않는다.

기존 필드별 후보·검토 요청·처리 사실과 당시 승인이 필요했던 기록은 [정책 인계 이력](./LAWYER-POLICY-HANDOFF-HISTORY.md)에 보존한다.
