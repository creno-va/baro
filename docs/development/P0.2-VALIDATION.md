공통 검증: 각 이슈의 bun ci/check/build/cf:dry-run과 해당 PR 정확한 head의 Quality gate.
최종 회귀는124 unit tests와15 browser tests이며 기존95 tests/6 browsers/50 합성 corpus를
포함한다. 50 oracle 테스트는 live model 품질 평가가 아니다.

전체 합성 흐름은 실제 서명 세션, auth/consent middleware, SQLite-backed D1 batch,
암호화 repository, 제품 execution runner, pinned gateway JSON/schema 경계 및 캡처한
공식 법령 adapter로 입력→dispatch→질문→unknown/skipped 답변→새 revision→공식 인용
검증 결과→재열람/refresh/back→선택 feedback→삭제를 확인한다. SDK opt-in flow와
revision 사이 논리적 admission hash를 함께 검증한다. 모델/플랫폼 실행은 test-only
adapter이며 실제 로그인/provider/Cloudflare Workflow 성공으로 표현하지 않는다.

실패 검증: quota 경합/자정,body hash 충돌,dependent/idempotency insert rollback,
dispatch create/checkpoint crash,phase 예약 유지/출력 재사용,stale revision/구 attempt,
24h 만료/10min process death,retry cap,모델 응답 중 삭제와 데이터 부활 방지.
UI는320px/200%zoom screenshot 확인,keyboard/focus/aria-live,loading/empty/error,
중복/503 same-key/409 stale/late,hidden/terminal polling 및새로고침/뒤로가기를 검증한다.

외부 call 성공과 checkpoint commit 사이의 중복 비용은 가능하다. phase 예약·교정 예산·
user attempt·timeout/Gateway spend limit으로 제한하며 exactly-once 과금을 주장하지 않는다.
남은 P0.3은 #17 account/Workflow cleanup·restore deletion drill,#18 live eval/security
release gate,#19 smoke/rollback/alerts,#20 법률·사업자·선택 지표 정책 승인,#27 환경별
OAuth/Turnstile/approved law OC/키/Gateway 예산·credit·payload logging/provider smoke다.
production 공개 전환,Environment 승인 우회,새 지출/자동 충전/모델 변경을 수행하지 않는다.
