## 디자인 시스템과 전역 원칙

Astro의 콘텐츠 화면과 React의 상호작용 영역에 shadcn 기반 공통 컴포넌트를 사용한다.
파란색 primary(초기 후보 #2563EB)를 semantic CSS 변수로 관리하고 흰색·중립색 표면,
위험·성공·대기 토큰을 분리한다. Pretendard를 기본 한글 font로 사용하고 파일/라이선스를
같이 관리한다. Lucide 크기·stroke·텍스트 동반·decorative aria-hidden 규칙을 통일한다.

브랜드는 공통 컴포넌트가 같은 SVG 파일을 참조한다. 임시 symbol은
`public/brand/logo.svg`로 두고 로고를 여러 TSX/페이지에 복제하지 않는다.
BARO text는 접근 가능한 브랜드 이름으로 제공하며 SVG 교체·캐시 갱신을 확인한다.

한 화면의 주 행동 하나를 강조하되 작업 맥락을 유지한다. 화면 이름·문구는 서비스
이용자 언어로 쓰고 내부 model/schema/Workflow 구현명을 필수 흐름에 노출하지 않는다.
실제 단계를 표시하고 가짜 %·시간 보장은 쓰지 않는다. 저장 성공과 진행 대기를 구분한다.
색만으로 상태를 표현하지 않으며 icons·labels·screen reader 안내를 제공한다.

AI가 권유하거나 자료를 무단 공유하는 CTA는 만들지 않는다.

## 적응형 사건 이해

초기 서술은 자유 입력 20~5,000 자이며 사건 가족·개인/기업 구분을 안내한다.
연령·지원 법역·자료 AI 처리 고지는 시작 전에 짧게 보여준다.

후속 질문은 답변에 따라 최대 세 묶음, 묶음당 최대 다섯 개다. 현재 단계와 저장 상태를
보여주고 총 질문 수가 미정인데 고정 완료 퍼센트를 표시하지 않는다.
text/choice 와 모름·건너뛰기를 동등하게 제공한다. 다음 묶음 생성 중에는 이전 답변을
다시 볼 수 있다. 저장된 사건은 새로고침·로그아웃 후 재로그인으로 이어갈 수 있다.
중복 클릭은 같은 작업을 재생하고 revision conflict는 최신 상태를 읽고 검토하게 한다.

요약 화면은 사용자 진술, 자료 기반 내용, AI가 정리한 내용, 추론/확인 필요를 구분한다.
날짜·금액·관계·누락·상충 내용을 편집/보완할 수 있고 `이 내용으로 계속하기`를 통해
명시적으로 확인한다. 법적 진실 확인이나 책임 면제로 오인될 문구는 쓰지 않는다.

## 작업 공간과 채팅

데스크톱은 사건 navigation 과 주 작업 영역을 두고, 모바일은 단일 열과 적은 수의
상단/하단 작업 진입으로 구성한다. chat·자료·리포트 이동에도 사건과 저장 상태를 유지한다.
scroll 와 focus를 작업 시작/에러 위치에 맞게 관리한다.

chat은 사용자 메시지와 검증 완료된 에이전트 응답을 구분하고 저장 시각·실패/재시도를
보여준다. 초안 streaming을 검증된 답변처럼 노출하지 않는다. 자료 인용은 파일·쪽·시간으로
이동하고 법률 인용은 검증된 공식 출처로 연다. 사용자 AI 일한도를 사용 전에 확인할 수 있다.

행동 목록은 왜 필요한지·확인할 자료/사실·주의점·진행 상태를 표시한다.
체크가 법적 절차 완료를 뜻하지 않음을 분명히 한다. 사용자 완료·보류는 서버에 저장한다.
진술 수정이나 새 자료로 상태가 바뀌면 이전 내용을 조용히 덮어쓰지 않고 변경을 표시한다.
법률 전략 질문은 변호사 확인 경로와 가능한 사실 정리 행동으로 이어간다.

## 자료와 자동 처리

업로드 화면에 지원 형식·100개/5GB·파일별 크기/시간·계정 10GB·일 60분 제한,
내용 AI 분석·외부 처리 고지와 동의를 표시한다. 동의한 upload는 자동 처리하지만
quota/예산 보류 상태는 성공으로 위장하지 않는다. 선택·취소·동시 upload 와 오류를 보여준다.

각 자료는 원본, 처리 상태, 자동 추출 내용, 출처 위치, 사용자 수정/확인, 삭제를 가진다.
문서는 쪽·이미지는 영역/추출 방식·음성/영상은 timestamp 와 coverage를 제공한다.
영상의 전체 음성 처리와 1초/장면전환 frame sampling을 설명하고 매프레임 확인을 주장하지 않는다.
원본을 못 읽은 구간·무음·손상·보호 파일·실패·quota 대기는 사용자 행동과 함께 표시한다.
미리보기는 owner 권한을 재검사하고 민감 파일명/내용을 public cache에 넣지 않는다.

## 리포트·원본 전달

리포트는 제목·생성시각·사건 revision·확인한 요약·경과·자료목록·출처/coverage·
불리한 사실/모순·미확인 점·준비 행동과 비자문 고지를 포함한다.
최신 사실과 달라진 과거 version은 `새 자료가 반영되지 않은 리포트`처럼 표시한다.

내보내기 전에 포함 내용·식별자·원본 선택을 검토한다. 이름 등 식별자는 기본 포함하되
수정/마스킹/제외를 제공한다. PDF 마스킹이 선택 원본을 바꾼다는 오해를 막고 ZIP 에는
선택한 원본만 담는다. PDF preview·생성대기·실패·재생성·다운로드를 제공한다.
사용자가 직접 전달하도록 안내하고 변호사에게 자동 발송하거나 공유권한을 부여하지 않는다.

## 변호사 자기 프로필 (ADR-0014)

통합 로그인에서 고객/변호사를 선택하고 변호사는 자기 portal로 이동한다.
프로필은 사진·이름·소개·사무실 주소·길찾기·연락수단·분야·포트폴리오를 편집한다.
작성·저장·미리보기·수정·재접속을 연결한다. 공개할 자산과 공개 동의를 구분한다.
role 선택이나 입력 프로필에 확인되지 않은 자격/검증/법률 승인 표시를 붙이지 않는다.

승인 어드민·자격 신청·반려·재신청·승인대기는 MVP 제외다. 자기 프로필 소유권을 검사하고
변호사 portal에 고객 사건·채팅·자료·리포트 원문 메뉴를 제공하지 않는다.

목록은 객관적 지역·분야 필터, 현재 등록수/부족, 회전 정렬 기준을 보여준다.
실제 확인 근거가 없는 프로필에 인증 표시를 하지 않으며 성과를 보장하지 않는다.
전화·email·외부상담·Naver/Kakao/Google 길찾기는 링크 목적과 외부 이동을 표시한다.

## 오류·제한·삭제 문구 기준

| 상태 | 사용자 문구 방향 | 다음 행동 |
| --- | --- | --- |
| 공식 근거 없음 | 공식 자료를 확인하지 못한 부분을 표시했어요 | 사실 정리 계속·원문 확인·변호사 질문 |
| AI 일한도 | 오늘 AI 응답 한도에 도달했어요. 저장된 자료는 볼 수 있어요 | 기존 자료·다음 KST 일 안내 |
| media/예산 대기 | 파일은 저장됐지만 자동 처리가 대기 중이에요 | 대기 이유·재개/취소·삭제 |
| revision 충돌 | 다른 화면에서 내용이 변경됐어요 | 최신 내용 불러오기·내 입력 검토 |
| 권한 없음 | 사건/자료/프로필을 찾을 수 없어요 | 소유 여부·존재 숨기고 목록 |

| 삭제 요청 | 접근을 차단하고 관련 자료를 정리하고 있어요 | 실제 primary/후속정리 상태 |
| v1 제한 | 이 사건은 이전 방식으로 정리한 사건이에요 | 과거 결과 조회/삭제·새 사건 |

계정 삭제는 실제 최근 OAuth 인증과 명시적 확인을 요구한다. URL/자동 callback 으로
삭제를 실행하지 않는다. 원본·파생물·리포트·프로필과 되돌릴 수 없음, backup 정리
정책을 설명한다. OAuth 취소는 비난하지 않고 다시 공급자를 선택할 수 있게 한다.

## 접근성과 시각 검증

영구 라벨·오류 연결·상태 aria-live, dialog focus trap/restore, focus visible,
최소 44×44px touch target, 색 대비·reduce motion·읽기 순서를 공통화한다.
320px·데스크톱·200% 확대·키보드만으로 전체 흐름을 확인한다.
font 로딩 실패 시 fallback 과 layout shift를 확인하고 혼합 한글·영문·숫자 가독성을 검토한다.

자동 axe 와 E2E 외에 실제 browser 에서 디자인·상태·다운로드·모달·upload·chat을 직접 확인한다.
Astro dev 성공은 built Worker의 hash CSP 성공을 대신하지 않는다.
화면 증거는 합성 내용만 사용하고 session/credential을 캡처하지 않는다.
