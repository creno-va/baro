# UX 및 화면 상태 명세

- Status: Implementation-ready
- Updated: 2026-10-04

## 전역 원칙

- 한 화면의 주 행동은 하나만 강조한다.
- 법률 용어 옆에 일상어 설명을 제공한다.
- 로딩 중 진행 단계를 표시하되 완료 시간을 보장하지 않는다.
- 오류는 원인 추측 대신 사용자가 할 수 있는 다음 행동을 말한다.
- 색만으로 상태를 구분하지 않고 아이콘·텍스트를 함께 쓴다.
- 모바일 320px부터 데스크톱까지 핵심 흐름과 출처가 잘리지 않아야 한다.

## 경로와 화면

| 경로 | 목적 | 주요 상태 |
| --- | --- | --- |
| `/` | 제품 범위와 한계 설명, 로그인 진입 | 기본, 인증됨 |
| `/login` | Google·Kakao 로그인 | 대기, 취소, 공급자 오류 |
| `/consent` | 필수 동의와 만 14세 이상 확인 | 미동의, 완료, 버전 갱신 |
| `/cases` | 내 사건 목록 | 로딩, 빈 목록, 목록, 오류 |
| `/cases/new` | 사건 입력·Turnstile | 입력, 검증 오류, 제출 중, 제한 초과 |
| `/cases/:caseId` | 질문 또는 분석 결과 | 질문, 대기, 결과, 실패, 범위 밖, 긴급 안내 |
| `/settings` | 정책 버전, 로그아웃, 계정 삭제 | 기본, 삭제 확인, 완료, 오류 |

## 핵심 화면

### 사건 입력

- 제목: `어떤 일이 있었는지 편하게 적어주세요`
- 보조: `이름, 주민등록번호, 계좌번호 전체처럼 꼭 필요하지 않은 정보는 적지 마세요.`
- 글자 수와 20자 미만·5,000자 초과 오류를 실시간 표시한다.
- 제출 버튼: `상황 정리 시작`
- 제출 직전에 AI 처리와 외부 서비스 전송 고지를 짧게 다시 노출한다.

### 추가 질문

- 현재 질문 수와 최대 수를 `2 / 최대 5개`처럼 표시한다.
- 각 질문에 자유 입력, 선택지, `모름`, `건너뛰기`를 제공한다.
- 답변 전송 후 뒤로 가기를 하더라도 중복 분석을 만들지 않는다.

### 분석 중

실제 서버 상태에 맞춰 `입력 확인`, `공식 자료 확인`, `결과 점검`을 표시한다.
가짜 퍼센트, `3초 안에 완료` 같은 보장은 하지 않는다. 장기 대기 시 화면을 떠나도
저장되며 목록에서 다시 확인할 수 있다고 안내한다.

### 결과

- 첫 화면에 AI·비자문 고지와 사건 요약을 둔다.
- 사용자 진술은 `사용자가 알려준 내용`, 모델의 정리는 `AI가 정리한 내용`, 누락은
  `확인 필요`로 시각적으로 구분한다.
- 출처는 법령명·조문·시행일·확인일을 보여주고 새 탭의 공식 URL로 연결한다.
- 체크리스트는 완료 상태를 브라우저에서 조작할 수 있으나 법적 완료를 의미하지 않는다.
- `도움이 됐나요?`는 선택 입력이며 분석 품질이나 기능 접근에 영향을 주지 않는다.

## 오류 문구 기준

| 상황 | 사용자 문구 | 행동 |
| --- | --- | --- |
| 범위 밖 | `현재는 대한민국의 개인 간 금전 대여 문제만 정리할 수 있어요.` | 범위 보기 |
| 일일 제한 | `오늘 만들 수 있는 새 분석 10회를 모두 사용했어요.` | 기존 사건 보기 |
| 일시 장애 | `지금은 분석을 완료하지 못했어요. 입력은 안전하게 저장됐습니다.` | 다시 시도 |
| 법률 출처 실패 | `공식 자료를 확인하지 못해 결과를 만들지 않았어요.` | 나중에 다시 시도 |
| 로그인 만료 | `안전한 이용을 위해 다시 로그인해 주세요.` | 로그인 |
| 권한 없음 | 존재 여부를 드러내지 않는 `사건을 찾을 수 없어요.` | 목록으로 |
| 삭제 완료 | `사건과 관련 분석을 삭제했어요.` | 목록으로 |

## 접근성

- 모든 입력에 영구 라벨과 구체적 오류 연결을 제공한다.
- 포커스 순서는 시각 순서와 일치하고 모달은 포커스를 가둔 뒤 원래 위치로 돌린다.
- 비동기 상태는 `aria-live`로 알리되 반복 안내를 피한다.
- 최소 44×44 CSS px 터치 목표와 200% 확대를 지원한다.
- 출처 링크의 목적을 링크 텍스트만으로 이해할 수 있게 한다.
- 모션 감소 설정을 존중하고 자동 재생 애니메이션을 사용하지 않는다.

## 인증·삭제 주의

OAuth 취소는 오류로 비난하지 않고 다시 선택할 수 있게 한다. 계정 삭제 확인에는
삭제되는 사건·분석·세션과 되돌릴 수 없음을 명시하고, 현재 로그인 재확인을 요구한다.
