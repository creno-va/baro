# 제품 로드맵

로드맵은 날짜 약속이 아니라 검증 순서다. 이전 단계의 안전·품질 게이트를 통과해야
다음 단계가 시작된다.

## P0 — 공개 베타

- 대한민국, 만 14세 이상, 개인 간 금전 대여
- Google·Naver·Kakao OAuth와 계정 저장
- 사건 입력, 최대 5개 질문, 검증된 법령 인용, 구조화 결과
- 사건·계정 삭제, 하루 10회, Turnstile
- Cloudflare 기반 배포·관측·장애 복구
- 정책 법률 검토와 랜딩 페이지 정합성 확보

## P1 — 품질과 활용성

- 사용자 피드백 기반 질문·결과 정보 구조 개선
- 법률정보 최신성 경보와 운영 검수 도구
- 증거 체크리스트의 안전한 진행 상태 저장
- 접근성·성능·실패 복구 개선
- 반복 사용 가치가 확인된 경우에만 추가 사건 유형 discovery

## P2 — 확장 후보

- 별도 데이터·정책·평가셋을 갖춘 사건 유형 확장
- 전문가 탐색이 필요하다면 중립적 디렉터리 또는 사용자가 직접 선택하는 외부 경로
- 사용자가 명시적으로 요청하고 검토 가능한 초안 보조

## 비목표

- 성공보수, 승소 가능성 기반 과금, 전문가 소개 수수료
- 무자격 법률 자문 또는 BARO 명의의 사건 판단
- 사용자를 대신한 서류 제출·연락·결제
- 검증되지 않은 판례 학습이나 `전국 인증 변호사` 같은 보장성 표현

새 사건 유형, 전문가 연결, 문서 생성은 각각 별도 PRD·ADR·법률 검토 없이는 P0에
합치지 않는다.
