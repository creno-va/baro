## v2 목표 변경과 새 공개 감사 — 2026-10-06

위 HTTP hash·PR/CI·checked 항목·교체 문안은 **v1 랜딩을 수정한 당시 증거**다.
[PRD v2](../PRD.md)는 변호사 탐색·직접 연락, 전 KR 사건 가족, 공식 판례/기관 안내,
자료·지속 chat·리포트를 새 목표로 채택했다. 이 문서 변경은 외부 랜딩이나 제품이 새
범위로 실제 배포되었다는 증거가 아니며 위 체크를 v2 승인/시연 완료로 재사용하지 않는다.

| v2 공개 표현 후보 | 게시 전 필요한 근거 |
| --- | --- |
| 변호사 프로필을 살펴보고 직접 연락 | 실제 본인 공개 프로필·객관적 필터·외부 링크·법률/게시 검토 |
| 사건 이해와 상담 준비를 돕는 AI | 질문/요약 확인/chat·허용 행동·안전 검증·비자문 고지 |
| 자료를 정리해 PDF 와 선택 원본으로 전달 | 실제 파일 처리·coverage·식별자 검토·PDF/ZIP·private 삭제·동의 |
| 대한민국의 다양한 법률 사건을 정리 | 전 사건 가족 preparation 평가·공식 source 확대·미확인 부분 안내 |
| 수수료 없이 이용 | 실제 초기 무료/소개수수료 없음, 적법성 보장으로 확장하지 않음 |

계속 금지한다. MVP 역할 선택과 프로필 등록을 자격 확인으로 표시하지 않는다. 자격·법률 승인 badge를 자동 생성하지 않는다.
정책 초안의 연락처/사업자 문구를 사실확인 없이 새 승인 사실로 취급하지 않는다.
