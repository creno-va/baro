# 공개 콘텐츠 정합성 감사

- Audited URL: `https://creno-va.github.io/baro-landing/`
- Audited: 2026-10-04
- Purpose: 공개 랜딩 문구와 승인된 MVP 범위의 출시 전 정합성 점검

## 결론

현재 랜딩 페이지는 승인된 MVP보다 넓고 일부 표현은 법률 판단 또는 전문가 알선으로
오인될 수 있다. 아래 항목을 수정하고 정책 문서와 함께 재검토하기 전에는 공개 베타의
정식 유입 페이지로 사용하지 않는다.

| 현재 공개 표현의 의미 | 충돌 | 필요한 수정 |
| --- | --- | --- |
| 사건 유불리 분석·진단 | BARO는 진단·유불리·승소 가능성을 제공하지 않음 | 상황 구조화, 확인할 쟁점, 준비 자료 안내로 교체 |
| 변호사 연결 및 소개 수수료가 핵심 수익 | P0/P1 범위 밖이며 이해상충·알선 검토 필요 | 전체 삭제. 재추진 시 별도 법률 검토와 ADR 필요 |
| 세무 서비스 제공 | MVP는 개인 간 금전 대여 법률정보 정리에 한정 | 삭제하거나 미래 검토 항목으로 비공개 전환 |
| 판례를 학습한 AI | 실제 설계는 공식 법령 검색 기반이며 판례 기능 없음 | 공식 법령 출처 기반이라고 정확히 표현 |
| 평균 3초 분석 | 다단계 워크플로의 측정값·SLO가 아님 | 시간 보장 삭제, 진행 상태와 저장 안내로 교체 |
| 전국 인증 변호사 연결 | 해당 네트워크와 검증 체계가 없음 | 삭제 |

## 유지 가능한 정보

공개된 운영자명 `CRENOVA`, 대표/개인정보 문의 담당 `황은찬`, 전화번호와 이메일은
정책 초안의 연락처와 일치시킨다. 사업자등록번호와 주소는 게시 전에 확정해야 한다.

## 출시 확인표

- [ ] 상단 가치 제안이 PRD의 제품 정의와 일치한다.
- [ ] 모든 진단·유불리·승소 가능성 표현을 제거한다.
- [ ] 변호사 알선·소개 수수료·세무 서비스 표현을 제거한다.
- [ ] `AI 생성`, `법률 자문 아님`, 지원 범위를 첫 CTA 이전에 표시한다.
- [ ] 개인정보 처리방침, 이용약관, AI 이용 고지를 실제 URL로 연결한다.
- [ ] 사업자 정보와 문의 연락처가 정책 문서와 일치한다.
- [ ] 시간·정확도·전문가 자격에 관한 검증되지 않은 보장을 제거한다.
