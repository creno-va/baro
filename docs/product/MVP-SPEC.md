# MVP 기능 명세

- Status: Implementation-ready
- Updated: 2026-10-04
- Related: [PRD](../PRD.md)

## 공통 조건

- 대한민국 개인 간 금전 대여 사건만 지원한다.
- 모든 기능은 로그인과 필수 동의를 요구한다.
- 신규 분석은 사용자별 한국시간 기준 하루 10회다.
- 서버의 권한·소유권·사용량 검사를 UI 상태보다 신뢰한다.
- 입력과 결과 원문은 애플리케이션 계층에서 암호화해 저장한다.

## 기능 요구사항

### F-001 가입·로그인·동의

사용자는 Google, Naver 또는 Kakao OAuth로 로그인한다. 최초 이용과 정책 버전 변경 시
이용약관, 개인정보 처리방침, AI 이용 고지에 동의하고 만 14세 이상임을 확인한다.
생년월일은 수집하지 않는다. 동의하지 않거나 만 14세 미만이면 사건을 만들 수 없다.

### F-002 사건 입력

사용자는 20~5,000자의 자유 서술을 입력한다. UI는 금액, 약정일, 변제기, 지급 방법,
상환 내역, 연락 내용, 보유 증거를 포함하도록 안내하되 필수 필드로 강제하지 않는다.
제출 시 Turnstile 토큰을 서버에서 검증한다.

### F-003 범위와 긴급성 판정

서버는 개인 간 금전 대여인지, 대한민국 법역인지, 즉시 안전 안내가 필요한지를 먼저
판정한다. 범위 밖이면 생성형 분석 대신 지원 범위와 공식 도움 경로를 표시한다.
자해·폭력·현재 진행 중인 위협 등 긴급 신호는 일반 분석보다 우선한다.

### F-004 추가 질문

분석에 필요한 중요 정보가 부족하면 최대 5개 질문을 한 번에 제시한다. 질문은 결과를
실질적으로 바꿀 수 있는 정보에만 한정한다. 사용자는 `모름` 또는 `건너뛰기`를 선택할
수 있고, 미확인 정보는 결과에서 명시한다.

### F-005 분석 결과

결과는 다음 순서와 필드를 가진다.

1. AI 생성 결과임과 법률 자문이 아님을 알리는 고지
2. 사용자 진술을 바탕으로 한 사건 요약
3. 날짜순 타임라인과 `확인 필요` 항목
4. 확인할 쟁점과 각 쟁점의 근거·불확실성
5. 증거 체크리스트와 사용자의 보유 상태
6. 일반적인 다음 행동과 주의점
7. 법령명·조문·시행일·공식 원문 링크가 있는 출처

승소 가능성, 확정적 법률 판단, 지어낸 사실, 검증되지 않은 출처는 표시하지 않는다.

### F-006 저장·목록·재열람

완료 또는 실패한 사건은 계정에 저장된다. 목록에는 사용자가 알아볼 수 있는 중립적
제목, 생성일, 상태만 표시한다. 사용자는 자신의 사건만 열람할 수 있다.

### F-007 사건·계정 삭제

사건 삭제는 확인 후 관련 분석·인용을 운영 D1에서 함께 삭제한다. 계정 삭제는 세션을
폐기하고 사용자 소유 사건과 인증 데이터를 삭제한다. 법적 보관 의무가 확인된 항목은
공개 정책과 구현에 동일하게 반영하기 전에는 별도 보관하지 않는다.

### F-008 오류와 재시도

일시 장애는 안전한 단계에서 멱등적으로 재시도한다. 실패한 분석은 내부 오류 원인을
노출하지 않고 다시 시도할 수 있다. 사용량은 같은 사건·입력 버전의 시스템 재시도로
중복 차감하지 않는다.

## 상태 모델

```text
draft -> screening -> needs_clarification -> queued -> analyzing
      -> completed
      -> failed -> queued (명시적 재시도)
      -> out_of_scope
      -> urgent_redirect

어느 비종료 상태에서든 -> deleted
```

동일 사건은 한 번에 하나의 활성 분석만 가진다. 추가 답변으로 입력 버전이 바뀌면 새
분석을 만들고 과거 결과는 사용자에게 정본으로 표시하지 않는다.

## P0 인수 조건

| 영역 | 인수 조건 |
| --- | --- |
| 인증 | 세 OAuth 공급자의 가입·로그인·로그아웃·계정 삭제가 preview/prod에서 동작한다. |
| 권한 | 다른 사용자의 사건 ID로 조회·삭제·재시도를 할 수 없다. |
| 입력 | 길이, 동의, Turnstile, 일일 제한을 서버가 검증한다. |
| 질문 | 질문이 5개를 넘지 않고 `모름/건너뛰기`가 결과에 반영된다. |
| 결과 | 모든 법률 주장은 검증된 출처 또는 명시적 불확실성에 연결된다. |
| 안전 | 출시 평가셋에서 허구 사실·미검증 인용·금지 출력이 0건이다. |
| 삭제 | 사건과 계정 삭제 후 API 및 운영 DB에서 재조회되지 않는다. |
| 장애 | 모델·법률 API·워크플로 장애가 개인정보 없는 오류 상태로 수렴한다. |
| 접근성 | 키보드만으로 전체 흐름을 완료하고 상태 변화가 보조기술에 전달된다. |

## 출시 금지 조건

- 정책 문서의 게시 차단 항목이 남아 있음
- 랜딩 페이지가 진단·유불리·변호사 알선·세무 지원을 현재 기능처럼 표현함
- 운영 환경에서 fixture 법률 데이터를 사용함
- AI Gateway 또는 애플리케이션 로그에 사건 원문·결과 원문이 남음
- 삭제·권한·인용 검증·안전 평가 중 하나라도 P0 실패
