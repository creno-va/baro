# AI 이용 고지와 v2 UI 문구

- Status: Public copy draft — legal/processing/publication review required
- Version: 2026-10-06-v2-draft
- Applies to: 홈·동의·질문·요약 확인·채팅·자료 처리·리포트·디렉터리·오류

#53 구현 목표의 초안이다. 현재 실제 모델/법률/전체 제품 성공 증거와 게시 승인 근거는
완료되지 않았다. 기존 2026-10-04-draft와 v1 동의 기록은 유지하며 새 copy를 자동 게시하지 않는다.
실제 출시 문구·동의 체크박스 분리·공급자/국외 처리·준비 행동 범위는 #68/#70에서 확정한다.

## 첫 CTA 이전 공통 고지

> BARO는 AI로 사건의 사실과 자료를 정리하고 변호사 상담 준비를 돕습니다. 질문과 정리
> 내용을 직접 확인해 주세요. AI는 변호사의 법률 판단·소송 전략이나 사건 결과를 보장하지 않습니다.

## 최초 이용과 자료 처리 확인

> 입력한 사건과 자료의 필요한 부분은 정리·생성·전사를 위해 Cloudflare 처리 경로와
> 합의한 AI 공급자에게 전달될 수 있습니다. 저장 자료는 암호화하지만 AI/파일 처리에 필요한
> 내용은 해당 처리 과정에서 읽을 수 있습니다. 필요하지 않은 개인정보는 제외하고 처리 목적,
> 항목과 국외 처리 내용을 개인정보 처리방침에서 확인해 주세요.

UI는 다음 확인을 구분해 보여준다. 법률상 consent와 단순 acknowledgment를 자동 동일시하지 않는다.

- 정책 버전·만 14세 이상 확인
- AI 사용과 법률 판단/결과 보장 아님을 이해
- 실제 provider/국외 처리 고지 및 해당 처리에 필요한 동의
- 파일별 자동 분석·audio/video 전사와 실제 처리 범위 확인
- 변호사 자기 프로필/포트폴리오 공개 동의와 공개 항목 확인

동의가 필요한 처리를 거부/철회하면 새 job을 보류·취소한다. 이미 저장한 원본의 보관·조회·
삭제와 이전 결과 처리 범위는 실제 정책에서 안내한다. 전사/원문을 model training에 임의
전용하지 않으며 요청의 logging/cache/store 옵션만으로 모든 provider 보존 없음이라 표현하지 않는다.

## 질문폼과 요약 확인

> 먼저 사건의 큰 흐름을 알려 주세요. 답변에 따라 확인할 질문이 이어집니다. 모르는 내용은
> ‘모름’, 아직 답하기 어려우면 ‘건너뛰기’를 선택할 수 있고 나중에 이어서 작성할 수 있습니다.

초기 질문은 작은 묶음으로 제시하며 5–10분은 설계 목표이고 완료 시간을 보장하는 광고가 아니다.

> 지금까지 알려주신 내용으로 정리했습니다. 사실·주장·확인 필요를 구분해 확인하고 잘못된
> 부분을 수정해 주세요. 요약을 확인한 뒤 자료와 다음 준비 행동을 정리합니다.

확인 버튼은 AI 요약의 법적 정확성·면책 동의가 아니다. 인물·날짜·금액·상반 진술·불리한
자료를 생략해서 확정하지 않고 source·confidence/unknown 상태를 표현한다.

## 지속 채팅과 행동

> 이 대화는 사건의 사실과 자료를 정리하는 데 사용됩니다. 준비 행동은 확인할 사실·자료에
> 관한 안내이며 법률 판단이나 합의·소송 전략이 아닙니다. 중요한 결정은 변호사에게 확인해 주세요.

작업별 저장/진행/실패·quota 상태를 표시한다. 실제 법률 검토된 행동 category 밖의 요청은
명확히 변호사에게 넘기며 대체 전략을 생성하지 않는다. 변호사 연락 이후에도 사실/자료 정리는
이어갈 수 있으나 담당 변호사의 판단을 AI가 대신 평가하지 않는다.

## 자료 처리와 coverage

> 업로드한 자료의 text·음성·선택 frame을 분석합니다. OCR·전사는 잘못 읽거나 일부를
> 놓칠 수 있습니다. 원본과 timestamp·처리 범위·누락 표시를 함께 확인해 주세요.

> 영상은 전 구간 audio와 매 1초/장면 변경 frame을 대상으로 합니다. 모든 frame을 확인한
> 것은 아닙니다. 음성 없는 구간이나 처리하지 못한 구간은 별도로 표시합니다.

파일별 duration/pages/format·처리 범위·오류/저품질/gap·원본 revision을 보여준다. unsupported/
partial coverage를 complete로 표시하지 않는다. 합의한 Whisper/vision 경로의 계정별 지원은
실제 smoke 이전에 제공 중이라고 광고하지 않는다. 원본의 진정성·법원 증거능력을 인증하지 않는다.

## 리포트·PDF·선택 원본

> AI가 정리한 상담 준비 자료입니다. 사실·주장·미확인·상반되는 자료와 출처를 확인해 주세요.
> 이름 등 식별정보는 기본적으로 남습니다. 전달 전 수정·가림·제외할 내용과 선택 원본을 확인해 주세요.

> PDF에서 가린 정보도 원본 파일에는 남을 수 있습니다. ZIP에 포함할 파일을 따로 확인하세요.
> 자료를 변호사에게 보내는 것은 이용자가 직접 결정하고 진행합니다.

리포트는 생성 시점/summary revision·파일 revision/coverage·출처 확인일을 표시한다. 법률
출처가 확인되지 않았더라도 사실 준비 자료를 만들 수 있으나 법률 검토 완료나 공식 제출
문서로 표현하지 않는다. 재생성은 새 version으로 남기고 사용자가 검토한 변경을 덮어쓰지 않는다.

## 공식 출처와 실패

> 법령·판례·기관 안내는 표시된 원문과 확인 시점을 기준으로 합니다. 사실과 적용 범위에
> 따라 해석이 달라질 수 있습니다. 중요한 판단은 원문과 전문가에게 확인해 주세요.

> 공식 자료를 확인하지 못했습니다. 확인되지 않은 법적 안내는 제공하지 않지만 입력한
> 사실과 자료는 계속 정리할 수 있습니다.

실제 upstream 오류·credential 문제·partial source 상태를 성공으로 표현하지 않는다. 법률
fixture·모델 기억·일반 검색 결과를 검증된 공식 근거로 대신하지 않는다.

## 변호사 프로필·연락

> 공개 프로필과 지역·분야를 확인하고 연락할 변호사를 직접 선택하세요. 본인 작성 정보이며
> 역할 선택과 등록은 자격 확인 증거가 아닙니다. 적합도나 상담·수임·성과를 보장하지 않습니다.

> 전화·이메일·상담 링크는 외부 연락 경로입니다. BARO가 사건 자료를 자동 전달하지 않습니다.

등록자 부족은 실제 빈 상태로 표시한다. AI 분석에 따른 추천/순위·유료 우선 노출과 허위
가상 프로필을 공개하지 않는다. 초기 소개 수수료가 없다는 사실을 적법성 보장으로 광고하지 않는다.

## 한도·보류·삭제

> 오늘 사용량 또는 처리 예산 때문에 자동 처리가 대기 중입니다. 이미 저장한 자료를 확인하거나
> 삭제할 수 있습니다. 이용 가능한 다음 행동과 다시 처리할 조건을 확인해 주세요.

사용량은 KST day3사건/30응답/60분media·계정10GB·사건100원본/5GB와 파일별 한도를 실제
구현과 맞춰 보여준다. retry는 같은 사용자 논리 작업의 quota를 중복 차감하지 않는다.

> 삭제 요청을 접수하고 접근을 차단했습니다. 원격 파일·처리 job 정리는 진행 상태에서 확인할 수
> 있습니다. 이미 다운로드하거나 외부 전달한 자료는 BARO에서 삭제할 수 없습니다.

202를 모든 backup/remote 즉시 삭제 완료로 표시하지 않는다. partial cleanup 실패는 보존하고
재처리·운영 확인을 요구한다. 계정 삭제에 실제 재인증이 필요한 이유와 명시적 확인을 안내한다.

## 긴급 상황과 금지 광고

즉시 위험·임박한 법정 기한은 AI 대기를 유도하지 않고 해당 공식 기관·자격 있는 전문가에게
확인하도록 안내한다. 확인되지 않은 긴급 번호나 기한을 생성하지 않는다.

다음 표현은 사용하지 않는다.

- 승소 가능성·유리한 재판 보장·확정 법률 판단·합의/소송 전략
- 변호사와 동일한 답·정확성/시간 보장·수임/상담 성립 보장
- AI가 고른 최적 변호사·인증이 업무 품질을 보장한다는 표현
- 영상 전 frame 확인·증거 진정성/법적 효력 인증
- Gateway 옵션만으로 모든 보존/학습/ZDR 없음·국내 전용 처리
- 수수료가 없으므로 합법·정책 초안을 이미 승인받았다는 표현

## 투명성 운영과 법률 검토

AI 사용/한계는 첫 CTA 이전에 안내하고 수정·차단 이유는 내부 prompt/보안정보를 노출하지 않는
고정 설명으로 제공한다. 모델·처리 목적·국외 흐름·public 게시 변경은 정책 버전/재동의를
검토한다. 신고를 평가로 재현할 때 실제 사건 원문을 artifact/공개 fixture로 복사하지 않는다.
게시 승인은 [이용약관](./TERMS.DRAFT.md)·[개인정보 초안](./PRIVACY-POLICY.DRAFT.md)의
차단 항목과 #70 증거를 함께 확인하며 시행일을 임의로 만들지 않는다.

[인공지능 기본법 제31조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031810729)는
실제 서비스의 AI 고지/투명성 의무 검토를 위한 공식 원문이다. 이 문서 작성이 해당 법률의
적용 분류·준수 완료 또는 변호사법상 적법성 승인이라는 뜻은 아니다.

현재 초안/UI 버전은 `2026-10-06-v2-draft`, 개발용 동의 버전은 `2026-10-04`다. 변경·게시·재동의는
법률/사업자/처리 경로 확인 후 4번 담당이 같은 release에서 확정한다. [필드별 인계](../development/LAWYER-POLICY-HANDOFF.md).
