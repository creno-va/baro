## 제2조 서비스 범위와 이용 자격

1. BARO는 대한민국 법률과 관련된 개인·회사 사건의 사실 정리, 상담 준비와 변호사
   탐색·직접 연락을 돕는다. 만 14세 이상이며 적법한 계정과 자료 입력 권한을 가진 사람이 이용한다.
2. 회사 사건도 한 작성자 계정이 관리한다. 조직 공동 편집·공유 workspace·권한 위임 기능이
   제공되는 것으로 해석하지 않는다. 변호사 공개 프로필은 개인 변호사 단위다.
3. Google/Naver/Kakao 로그인과 필요한 동의를 사용한다. 로그인 공급자의 승인·서비스 상태에
   따라 이용할 수 없는 경우를 표시하고 같은 이메일만으로 계정을 자동 병합하지 않는다.
4. 공개 승인 후 변호사 탐색은 로그인 없이 가능하며 사건 저장·AI·자료 기능에는 로그인이 필요하다.
   계정/세션 양도·공유, 만 14세 미만 이용과 권한 없는 자료 등록을 허용하지 않는다.

## 제3조 사건 준비와 AI의 한계

1. 질문폼은 큰 틀의 질문과 답변에 따른 추가 질문을 제시한다. 모름·건너뛰기·중단·재개를
   지원하고 이용자가 요약을 확인·수정한 뒤 채팅·자료·타임라인·다음 행동 정리를 진행한다.
2. 모든 대한민국 법률군을 입력 대상으로 하더라도 모든 사건의 법적 판단이나 완전한 출처
   확보를 보장하지 않는다. 확인할 수 없는 사실·출처·처리 구간을 분리해서 표시한다.
3. AI는 이용자 진술과 자료를 정리하고 법률 검토된 준비 행동 범위 안에서 확인할 사실과 자료를
   안내한다. 법률 자문·수임·대리·승소 가능성·법적 유불리 판정·합의나 소송 전략을 제공하지 않는다.
4. 이용자는 중요한 결정을 변호사/관계 기관에 확인한다. 긴급한 위험이나 기한이 임박한 경우
   AI를 기다리지 않는다. 이 내용은 이용자의 법정 권리나 운영자의 법적 책임을 면제하는 조항이 아니다.
5. 공식 법령·판례·기관 안내는 각 확인 시점과 출처를 표시하고 검증되지 않은 법적 행동은
   제시하지 않는다. 출처 장애가 있어도 사실 정리 자료를 만들 수 있으나 법률 검증 완료로 표기하지 않는다.
6. 변호사에게 연락한 뒤에도 자료·사실 정리는 이어갈 수 있다. 이미 위임한 변호사의 전략을
   AI가 검토/대체하도록 설계하지 않는다.

## 제4조 변호사 프로필과 연락

1. 변호사는 본인·자격·사무실 확인 신청 후 사진·이름·소개·주소·분야·연락 수단과
   포트폴리오(text/image/PDF)를 등록한다. 모든 공개 편집은 별도 심사를 거친다.
2. 심사 중인 revision은 현재 승인된 공개 프로필을 덮어쓰지 않는다. 반려 이유를 확인하고
   재신청할 수 있다. 자격·프로필 심사 범위는 법률 검토를 거쳐 공개하며 업무 품질·성과 보장이 아니다.
3. 이용자는 객관적 지역·분야 필터와 투명하게 안내되는 순환 순서로 변호사를 탐색한다.
   사건 분석에 따른 AI 적합도 순위, 유료 우선 노출, 성과를 보장하는 추천을 제공하지 않는다.
4. 전화·이메일·외부 상담 링크, 네이버/카카오/구글 길찾기는 이용자가 직접 선택한다.
   연락처 열람은 상담 성립·수임 보장을 의미하지 않는다. 지역·분야에 등록자가 없으면 실제 부족 상태를 표시한다.
5. BARO 내부 메시지·자동 사건 전달·수임 계약·변호사 비용 결제는 제공하지 않는다.
   상담/위임 조건과 비용은 이용자와 변호사가 직접 확인하고 계약한다.
6. 초기 서비스는 이용료와 사건 소개/수임 수수료를 받지 않는다. 이 구조만으로 적법성을
   단정하지 않으며 실제 운영·광고·AI 행동 범위는 별도 법률 검토 대상이다.
   [변호사법 제34조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1008649267)

## 제5조 자료 처리와 내보내기

1. 이용자는 입력·업로드·공개할 권한을 확인하고 불필요한 민감정보와 제3자 개인정보를 최소화한다.
   자료 자동 분석·외부 AI/음성 처리에 필요한 안내와 동의를 확인한 뒤 처리 job을 시작한다.
2. 문서·이미지·audio/video의 원본과 추출 결과를 보관한다. audio는 전 구간 전사,
   video는 전 audio와 매 1초/장면 변경 frame을 대상으로 하며 모든 frame을 확인한 것은 아니다.
   오류·저품질·누락·시간 구간과 실제 coverage를 표시한다. 전사/OCR는 사실·원본 진정성 증명이 아니다.
3. 요약·리포트는 확인된 사실, 이용자 주장, 확인 필요, 상반되거나 불리한 자료와 출처를 구분한다.
   이용자는 리포트를 확인·수정·가림·제외할 수 있으며 PDF와 선택 원본 ZIP을 직접 내려받는다.
4. 식별정보는 기본적으로 자동 제거되지 않는다. PDF 가림은 원본 파일 가림을 의미하지 않으며
   선택한 원본에 식별정보가 남는지 별도로 확인해야 한다. 이용자가 외부 전달할 수신자와 자료를 결정한다.
5. 운영자는 자료를 변호사에게 자동 전달하지 않는다. 외부 전달/다운로드된 copy는 BARO 삭제와
   별개이며 수신자의 이용·보관은 해당 관계와 법률에 따라 확인해야 한다.

## 제6조 한도·대기·서비스 변경

초기 정책은 다음과 같다. byte 단위는 decimal 기준이며 실제 용량/시간/pages를 검사한다.

| 대상 | 한도 |
| --- | --- |
| 계정 KST 하루 | 신규 사건 3개, AI 응답 30회, audio/video 처리 60분 |
| 사건 | 원본 100개, 저장 5GB |
| 계정 | 저장 10GB |
| 문서·이미지 | 파일당 100MB |
| audio/video | 파일당 1GB 및 60분 |
| PDF | 파일당 500 pages 및 문서 byte 한도 |

저장량은 원본·파생·리포트·ZIP·진행 중 예약을 포함하고 계정에는 프로필 자산도 포함한다.
같은 논리 작업의 retry는 사용자 한도를 중복 차감하지 않는다. 자원·전역 예산·외부 서비스
상태에 따라 자동 처리가 대기/보류될 수 있으며 UI에서 이유와 가능한 다음 행동을 안내한다.
이는 무료 이용이 무제한 처리임을 뜻하지 않는다. quota/예산 부족 때 이미 저장한 자료의
조회·download·삭제를 유지하도록 설계한다. 운영상 제한·중요 변경은 사유와 영향을 고지한다.

## 제7조 권리와 금지 행위

이용자는 자신의 입력에 대한 권리를 유지한다. 운영자는 서비스 제공·보안·삭제에 필요한
범위에서 처리하며 사건 내용을 광고·판매하거나 모델 학습 자료로 임의 전용하지 않는다.
변호사 공개 프로필 자료는 승인된 공개 목적 범위에서 게시한다. 공개로 올릴 제3자 사건 자료는
권리/비밀 유지·개인정보 공개 가능성을 확인하고 필요한 가림을 해야 한다.

타인 권리 침해·허위 자격/성과·사칭·위법 행위 지원·spam·자동화 과다 요청·출처/권한/비용
제어 우회·악성 파일 등록을 금지한다. 위반이나 정보 누출 의심은 범위별 접근/공개를 차단하고
사유·이의 제기 경로를 안내한다. 신분/프로필 심사자에게 사건 원문 열람 권한을 부여하지 않는다.

## 제8조 저장·삭제·계정 종료

사건·자료·채팅·리포트는 이용자가 삭제하거나 계정을 삭제할 때까지 저장한다. 세부 처리와
보유 기간은 개인정보 처리방침을 따른다. 계정 삭제에는 최근 실제 OAuth 재인증과 명시적
확인이 필요하며 세션/primary 접근을 즉시 폐기하고 원격 파일·job·public 자산을 비동기 정리한다.
202 접수는 모든 backup과 원격 저장물의 즉시 파기 완료가 아니다. 실패는 완료로 숨기지 않는다.
backup 복구 시 DB 밖 최신 삭제 journal을 재적용하기 전 서비스를 다시 열지 않는다.

## 제9조 책임·변경·분쟁

운영자는 관련 법령의 서비스 안전/개인정보/계약 의무를 이행해야 한다. 외부 장애·입력 오류에
대한 책임 범위는 실제 사정과 관련 법령을 따르며 고의·중과실 책임과 이용자의 법정 권리를
부당하게 제한하지 않는다. 기능/약관 변경·중단은 시행일·변경 이유·자료 조회/삭제 방법을 알리고
필요한 별도 동의와 법정 절차를 따른다. 대한민국 법률과 법정 관할/분쟁 절차를 따르는 조항은
최종 법률 검토로 확정한다. 문의 경로는 제1조의 실제 확인된 연락처를 게시한 뒤 제공한다.
